# v0.1.1 — 桌面端补齐专利线

在 v0.1.0 端侧离线客户端的基础上，补齐了客户端的**专利申请线**，并修正了一个会导致专利案例走错流程的缺陷。

## 下载

| 平台 | 文件 | 说明 |
| --- | --- | --- |
| Windows x64 | `SoftCopyright-Desktop-win-x64.zip` | 自包含，解压即用 |
| macOS Apple Silicon | `SoftCopyright-Desktop-macos-arm64.tar.gz` | 交叉发布，需在 Mac 上赋可执行权限 |
| Linux x64 | `SoftCopyright-Desktop-linux-x64.tar.gz` | 交叉发布，需 `chmod +x` |
| Android | `SoftCopyright-Android-arm64-v8a-x86_64.apk` | 含 arm64-v8a 与 x86_64 |

桌面端为自包含发布，**目标机器无需安装 .NET 运行时**。

### 安装与运行

- **Windows**：解压到任意目录，运行 `SoftCopyright.Desktop.exe`。
- **macOS**：`tar -xzf SoftCopyright-Desktop-macos-arm64.tar.gz && chmod +x SoftCopyright.Desktop && ./SoftCopyright.Desktop`。
- **Linux**：`tar -xzf SoftCopyright-Desktop-linux-x64.tar.gz && chmod +x SoftCopyright.Desktop && ./SoftCopyright.Desktop`。
- **Android**：安装 APK 后打开「知识产权申请材料工具」。APK 为自签名证书签名，系统可能提示"未知来源"，需手动允许安装。

## 本版本的主要变化

### 客户端的专利线（新增）

上一版客户端只覆盖软著线。专利线的引擎能力（`IPatentService`、`IPatentDocumentGenerator`、`PatentConfirmationGate`）本就���绪，本版本把它们接到了界面上：

- 新增**「专利交底书」步骤**：填写发明名称、技术领域、背景技术、技术问题、技术方案、有益效果、附图说明、现有技术与其来源、申请人与发明人；
- 支持**保存交底书**、**保存并生成草稿**、**确认草稿**；
- 草稿生成后可直接预览**摘要**与**权利要求列表**（编号、独立/从属类型、引用关系），便于逐条核对。

### 修正：流程步骤按案例类型分化

上一版的侧栏步骤是软著专用的，**新建专利案例后仍会被导到「申请信息」「代码材料」**——而专利申请文件不含代码鉴别材料，这条路径本身就是错的。

本版本起，侧栏步骤集合按当前案例的材料类型重建：

| 步骤 | 软著线 | 专利线 |
|---|---|---|
| 案例 / 导入仓库 / 分析与证据 | ✅ | ✅ |
| 申请信息 / 代码材料 | ✅ | ❌ |
| 专利交底书 | ❌ | ✅ |
| 材料与导出 | ✅ | ✅ |

切换案例时若当前步骤不属于新流程，会自动回到「案例」；上一步 / 下一步按当前流程的顺序走，不会跳到别的流程的步骤。

### 补齐确认门禁

材料页新增**「确认草稿」**与**「确认最终材料」**两个操作，与 Web 端的门禁语义对齐：

| 门禁 | 软著线 | 专利线 |
|---|---|---|
| 生成材料前 | 申请信息 + 代码范围 + 草稿确认 | 草稿确认（交底书与权利要求就绪） |
| 归档 | 最终材料确认 | 最终材料确认 |

上一版桌面端可以直接跳过草稿确认生成材料，本版本会明确拒绝并提示原因。

### 其他

- 侧栏步骤按钮改为数据驱动渲染（`ItemsControl` + `DataTemplate`），步骤增减不再需要改 XAML。
- 新增 `--demo-patent` 启动参数，用于生成带样例交底书与已生成权利要求的专利演示案例。
- 修正 `scripts/build-mobile.ps1` 的工作负载检测逻辑（原先会把已安装的 android 误判成未安装）。

## 数据与隐私

- 数据全部落在本机 SQLite，数据目录为 `~/.softcopyright`（Windows：`%USERPROFILE%\.softcopyright`），可用环境变量 `SOFTCOPYRIGHT_DESKTOP_DATA_ROOT` 改写。
- **默认不接入任何模型服务**，所有材料由本机规则与证据生成，不会产生外部请求。
- 若自行配置模型 API 密钥，密钥经 AES-256-GCM 加密后存入本机库，机器密钥 `secret.key` 位于数据目录。
- 源码正文不会写入日志。

## 已知限制

- **不生成或改写登记用源码**：本工具负责组织材料与校验，登记用的源程序/文档仍需由申请人按官方要求自行准备。
- **不保证登记通过**：官方审核结果由版权保护中心决定。
- **专利附图不生成**：只产出「附图说明」章节，流程图与结构图由申请人补充。
- **保护范围等法律判断不代劳**：权利要求的保护范围、新颖性与创造性必须由专利代理人复核；工具只产出初稿。
- macOS / Linux 产物为在 Windows 上交叉发布，未在目标设备上完整验证；Windows 版本已在 Windows 11 上实际运行验证。
- Android 仅覆盖 arm64-v8a 与 x86_64，不含 32 位设备，且未在真机/模拟器上跑过。
- 鸿蒙（HarmonyOS / ArkTS）本期**未支持**。
- 账号体系为客户端单用户模型（本机内置管理员，无登录页）。
