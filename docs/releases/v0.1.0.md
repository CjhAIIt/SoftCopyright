# v0.1.0 — 首个可运行版本（端侧离线原生客户端）

本版本把项目从 Web 服务形态转为**端侧离线原生客户端**：分析与取证、材料生成、校验与导出全部在本机完成，不需要服务器、不上传源码。

## 下载

| 平台 | 文件 | 说明 |
| --- | --- | --- |
| Windows x64 | `SoftCopyright-Desktop-win-x64.zip` | 自包含，解压即用 |
| macOS Apple Silicon | `SoftCopyright-Desktop-macos-arm64.tar.gz` | 交叉发布，需在 Mac 上赋可执行权限 |
| Linux x64 | `SoftCopyright-Desktop-linux-x64.tar.gz` | 交叉发布，需 `chmod +x` |
| Android | `SoftCopyright-Android-arm64-v8a-x86_64.apk` | 含 arm64-v8a 与 x86_64 |

桌面端为自包含发布，**目标机器无需安装 .NET 运行时**。

### 安装与运行

- **Windows**：解压到任意目录，运行 `SoftCopyright.Desktop.exe`。
- **macOS**：`tar -xzf SoftCopyright-Desktop-macos-arm64.tar.gz && chmod +x SoftCopyright.Desktop && ./SoftCopyright.Desktop`。
- **Linux**：`tar -xzf SoftCopyright-Desktop-linux-x64.tar.gz && chmod +x SoftCopyright.Desktop && ./SoftCopyright.Desktop`。
- **Android**：安装 APK 后打开「知识产权申请材料工具」。APK 为调试/自签名证书签名，系统可能提示"未知来源"，需手动允许安装。

## 本次包含的功能

- 软著与专利两条独立流程：案例管理 → 导入仓库 → 分析与取证 → 申请信息 → 代码材料 → 材料与导出。
- 软著申请信息按《中国版权保护中心·计算机软件著作权登记申请表填写说明》收敛为**官方规定候选项**，支持条件必填与跨字段约束（如「原始取得」须「单独开发」），历史自由文本自动归一化。
- 材料生成前的确认门禁：缺失项、条件必填项、跨字段冲突会逐条列为"需申请人处理"，不由 AI 代填。
- 深色 / 浅色双主题，偏好保存在本机。
- 窄屏（手机）自动切换为单列布局 + 底部导航，宽屏为三列 + 侧栏，同一套界面代码。

## 数据与隐私

- 数据全部落在本机 SQLite，数据目录为 `~/.softcopyright`（Windows：`%USERPROFILE%\.softcopyright`），可用环境变量 `SOFTCOPYRIGHT_DESKTOP_DATA_ROOT` 改写。
- **默认不接入任何模型服务**，所有材料由本机规则与证据生成，不会产生外部请求。
- 若自行配置模型 API 密钥，密钥经 AES-256-GCM 加密后存入本机库，机器密钥 `secret.key` 位于数据目录。
- 源码正文不会写入日志。

## 已知限制

- **不生成或改写登记用源码**：本工具负责组织材料与校验，登记用的源程序/文档仍需由申请人按官方要求自行准备。
- **不保证登记通过**：官方审核结果由版权保护中心决定。
- macOS / Linux 产物为在 Windows 上交叉发布，未在目标设备上完整验证；Windows 版本已在 Windows 11 上实际运行验证。
- Android 仅覆盖 arm64-v8a 与 x86_64，不含 32 位设备。
- 鸿蒙（HarmonyOS / ArkTS）本期**未支持**。
- 账号体系为客户端单用户模型（本机内置管理员，无登录页）。
